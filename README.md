# FloraVision - Product Listing Page

## 📌 Overview

This project is a responsive Product Listing Page built using React and Vite based on the provided Figma design.

## 🚀 Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript

## ✨ Features

- Responsive Design
- Product Cards
- Clean UI
- Fast Performance

## 📦 Installation

```bash
npm install
```

## ▶️ Run Locally

```bash
npm run dev
```

## 🏗️ Build

```bash
npm run build
```
